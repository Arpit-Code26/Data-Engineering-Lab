
# Retail Sales Data Pipeline - Assignment 1 Mini Project

## Project Components:
- **sales.csv** - Sample dataset with captured and stored retail sales transactions.
- **analyze_data.py** - Complete Python pipeline for loading, cleaning, analyzing, and visualizing the sales data.
- **Figures 1 & 2** - Visual outputs (bar chart for product sales, pie chart for customer spending) generated by the script.

## Overview
This mini project demonstrates the end-to-end data lifecycle of retail sales data including:
- Data capture and storage (CSV file)
- Data cleaning and processing
- Exploratory data analysis to extract insights like total sales, best-selling product, and customer spending
- Visualization of results through charts for better understanding

## Technologies Used
- Python, Pandas, Matplotlib

## How to Run
1. Place the `sales.csv` file and the Python script `analyze_data.py` in the same directory.
2. Install required packages if needed:
   ```
   pip install pandas matplotlib
   ```
3. Run the script:
   ```
   python analyze_data.py
   ```
4. View the console output and plotted figures.
