# Employee Data Cleaning Project

This project cleans and validates an employee dataset using Python and pandas.

## Files
- `employee_data.csv`: Raw employee data.
- `employee_cleaned2(1).csv`: Cleaned data after processing.
- `Experiment-1-Assignment-2.ipynb`: Notebook with cleaning and validation code.

## Dataset Fields
- Employee ID, Name, Email, Joining Date, Department, Salary

## Process
1. Load raw data and fix formatting issues.
2. Remove duplicate rows.
3. Validate emails and mark invalid ones as missing.
4. Check for missing important values.

## How to Use
- Open and run the notebook in Jupyter.
- Make sure CSV files are correctly located.
- Run cells step-by-step to clean and validate data.

This project shows basic data cleaning steps needed before analysis or modeling.
